Todo lo que necesitas para crear tu página web

Crear una página web implica muchas decisiones: qué dominio elegir, dónde alojarla, cómo diseñarla, qué textos poner, cómo hacer que Google la encuentre... Nosotros nos encargamos de todo para que tú no tengas que ser experto en nada de eso.

  • Asesoramiento inicial: te ayudamos a definir la estructura, las secciones y el contenido de la web
  • Elección del dominio: te ayudamos a elegir el mejor nombre de dominio y a registrarlo
  • Diseño a medida: creamos el diseño visual adaptado a tu imagen de marca
  • Redacción y estructuración del contenido: editamos y optimizamos tus textos para el SEO
  • Alojamiento gratuito: la web alojada en Vercel sin coste mensual
  • Alta en Google Search Console: para que Google indexe tu web desde el primer día
  • Formación básica: te explicamos cómo actualizar el contenido cuando lo necesites

Qué tipos de página web podemos crear

No todas las webs son iguales. El tipo de página web que necesitas depende de tu negocio y de tus objetivos. Las opciones principales:

  • Web de presentación: la más habitual para autónomos y pymes. Quién eres, qué ofreces, cómo contactarte y dónde encontrarte. Sencilla, eficaz y asequible
  • Web corporativa: para empresas que necesitan transmitir una imagen más elaborada, con varias secciones, equipo, valores y casos de éxito
  • Tienda online: para vender productos por internet con pagos, stock y gestión de pedidos
  • Web con reserva online: para restaurantes, clínicas, hoteles o cualquier negocio que necesite gestionar citas o reservas
  • Landing page: una única página optimizada para una campaña o un servicio concreto

Preguntas frecuentes

No tengo ningún conocimiento técnico. ¿Puedo tener web igualmente?

Sí, es justo para quien no tiene conocimientos técnicos. Tú aportas el conocimiento de tu negocio y nosotros nos encargamos de toda la parte técnica. Al final tienes una web profesional sin haber aprendido a programar.

¿Qué archivos o información tendré que preparar?

Principalmente: una descripción de tu negocio y tus servicios, tu logotipo (si tienes), fotos del negocio o de los productos y los datos de contacto. Si no tienes logotipo o fotos, te orientamos sobre cómo conseguirlos.

¿Cuánto dura todo el proceso?

De la primera reunión a la web publicada, normalmente entre 1 y 3 semanas. Depende de la complejidad de la web y de la rapidez con que se pueda preparar el contenido. Te damos un calendario concreto en el presupuesto.

¿Tendré que pagar algo cada mes?

No hay cuotas mensuales obligatorias. El alojamiento es gratuito. El único coste recurrente es el dominio (8-15 €/año). Si quieres el servicio de mantenimiento, es opcional y tiene un coste mensual reducido.
