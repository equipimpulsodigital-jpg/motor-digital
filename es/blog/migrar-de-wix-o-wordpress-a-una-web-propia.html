Migrar de Wix o WordPress a una web propia: cómo hacerlo sin perder nada

Muchas pymes empiezan con Wix o WordPress porque es rápido y barato, y acaban topando con sus límites: velocidad, diseño genérico o costes que suben con el tiempo. Migrar es más sencillo de lo que parece si se hace con un plan claro.

Por qué vale la pena dejar Wix o WordPress

Wix y WordPress son buenas herramientas para empezar, pero con el tiempo muestran sus límites: plantillas que se parecen a las de la competencia, velocidad de carga limitada por el exceso de plugins, y cuotas mensuales que no bajan nunca. Una web hecha a medida elimina estas limitaciones.

Cómo se hace la migración paso a paso

1. Recopilar todo el contenido de la web actual

Textos, imágenes, vídeos y cualquier documento que ya funcione bien se recupera antes de empezar, para no tener que reescribirlo todo desde cero.

2. Listar todas las URL que ya posicionan en Google

Este es el paso que más a menudo se pasa por alto y el que hace perder SEO en una migración mal hecha. Hay que saber qué páginas reciben visitas antes de tocar nada.

3. Desarrollar la web nueva en paralelo

La web antigua sigue activa mientras se construye la nueva, de manera que no hay tiempo muerto ni pérdida de visitas durante el proceso.

4. Redirecciones 301 de cada URL antigua a la nueva

Cuando una URL cambia, una redirección 301 le dice a Google "esta página se ha movido aquí" y transfiere el posicionamiento acumulado en lugar de perderlo.

5. Verificar Analytics y Search Console después del cambio

Una vez hecha la migración, hay que revisar que Google siga indexando las páginas correctamente y que no hayan aparecido errores 404 inesperados.

Errores habituales a evitar

  • Cambiar las URL sin configurar ninguna redirección, perdiendo todo el SEO acumulado
  • Dar de baja la web antigua antes de que la nueva esté completamente indexada
  • No avisar a Google Search Console del cambio de dominio si también se cambia
  • Perder contenido o imágenes que ya funcionaban bien por prisas en el proceso

Preguntas frecuentes

¿Perderé el posicionamiento de Google si cambio de plataforma?

Si se hace bien, no. La clave es mantener las mismas URL (o redirigirlas correctamente con redirecciones 301) y conservar el contenido que ya funcionaba. Hecho así, Google normalmente mantiene el posicionamiento o incluso lo mejora si la web nueva es más rápida.

¿Cuánto tarda migrar una web de Wix o WordPress?

Para una web de presentación de tamaño medio, suele tardar entre 1 y 3 semanas: recoger contenido e imágenes de la web antigua, desarrollar la nueva, revisarla y hacer el cambio de dominio con las redirecciones correspondientes.
