Migrar de Wix o WordPress a una web pròpia: com fer-ho sense perdre res

Moltes pimes comencen amb Wix o WordPress perquè és ràpid i barat, i acaben topant amb els seus límits: velocitat, disseny genèric o costos que pugen amb el temps. Migrar és més senzill del que sembla si es fa amb un pla clar.

Per què val la pena deixar Wix o WordPress

Wix i WordPress son bones eines per començar, però amb el temps mostren els seus límits: plantilles que s'assemblen a les de la competència, velocitat de càrrega limitada per l'excés de plugins, i quotes mensuals que no baixen mai. Una web feta a mida elimina aquestes limitacions.

Com es fa la migració pas a pas

1. Recopilar tot el contingut de la web actual

Textos, imatges, vídeos i qualsevol document que ja funcioni bé es recupera abans de començar, perquè no cal reescriure-ho tot des de zero.

2. Llistar totes les URL que ja posicionen a Google

Aquest és el pas que més sovint s'obvia i el que fa perdre SEO en una migració mal feta. Cal saber quines pàgines reben visites abans de tocar res.

3. Desenvolupar la web nova en paral·lel

La web antiga segueix activa mentre es construeix la nova, de manera que no hi ha temps mort ni pèrdua de visites durant el procés.

4. Redireccions 301 de cada URL antiga a la nova

Quan una URL canvia, una redirecció 301 diu a Google "aquesta pàgina s'ha mogut aquí" i transfereix el posicionament acumulat en lloc de perdre'l.

5. Verificar Analytics i Search Console després del canvi

Un cop feta la migració, cal revisar que Google segueixi indexant les pàgines correctament i que no hagin aparegut errors 404 inesperats.

Errors habituals a evitar

  • Canviar les URL sense configurar cap redirecció, perdent tot el SEO acumulat
  • Donar de baixa la web antiga abans que la nova estigui completament indexada
  • No avisar Google Search Console del canvi de domini si també es canvia
  • Perdre contingut o imatges que ja funcionaven bé per presses en el procés

Preguntes freqüents

Perdré el posicionament de Google si canvio de plataforma?

Si es fa bé, no. La clau és mantenir les mateixes URL (o redirigir-les correctament amb redireccions 301) i conservar el contingut que ja funcionava. Fet així, Google normalment manté el posicionament o fins i tot el millora si la web nova és més ràpida.

Quant triga migrar una web de Wix o WordPress?

Per a una web de presentació de mida mitjana, sol trigar entre 1 i 3 setmanes: recollir contingut i imatges de la web antiga, desenvolupar la nova, revisar-la i fer el canvi de domini amb les redireccions corresponents.
